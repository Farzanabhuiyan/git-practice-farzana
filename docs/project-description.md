# Project Description

## Overview

The Git Practice Project is a Python-based project created for the Module 8 Git & GitHub Practical Assignment.

The project demonstrates how Git can be used to track changes, create feature branches, merge development work, and synchronize a local repository with GitHub.

## Features

The project currently provides the following calculator operations:

- Addition
- Subtraction
- Multiplication

The main program also displays the student's name and the current date.

## Git Workflow

The project demonstrates the following Git workflow:

1. Initialize a local Git repository.
2. Create and track project files.
3. Make meaningful commits.
4. Create feature branches.
5. Develop features on separate branches.
6. Merge completed features into the main branch.
7. Push the project to GitHub.
8. Add error handling through a separate feature branch.

## Technologies

- Python
- Git
- GitHub

## Learning Outcome

This project provides practical experience with version control, branching, merging, commit management, and remote repository management using Git and GitHub.
