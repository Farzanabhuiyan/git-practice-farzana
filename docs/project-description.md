# Project Description

## Overview

This project is a practical demonstration of Git and GitHub fundamentals.

The project contains a simple Python program that displays the student's name and the current date. It also includes calculator functions for addition, subtraction, multiplication, and division with basic error handling.

## Purpose

The purpose of this project is to demonstrate:

- Git repository initialization
- Creating commits
- Working with branches
- Merging branches
- Connecting a local repository to GitHub
- Pushing a project to GitHub
- Maintaining a proper project structure

## Technologies Used

- Python
- Git
- GitHub
